# Domain Docs

This repo uses a **single-context** layout.

- `AGENTS.md` at repo root — agent-facing project overview, stack, architecture, and working rules.
- `CONTEXT.md` at repo root — shared product vocabulary and behavior.
- No `docs/adr/` directory exists yet; architectural decisions are implicit in `AGENTS.md` and code.

When exploring the codebase, respect the module boundary rules documented in `AGENTS.md`.
