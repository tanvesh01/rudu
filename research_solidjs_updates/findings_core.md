# SolidJS core updates — August 15, 2026

- **Solid 2.0 reached RC on August 13, 2026, but is not GA.** npm currently tags `2.0.0-rc.0` as `next`; `latest` remains Solid 1.x (`1.9.14`). Sources: [RC release](https://github.com/solidjs/solid/releases/tag/v2.0.0-rc.0), [npm registry](https://registry.npmjs.org/solid-js).
- **Async is now part of the reactive graph.** Ordinary computations can return Promises or async iterators. `<Loading>` handles initial readiness, while `isPending` represents revalidation and stale content can remain visible. Source: [RC release](https://github.com/solidjs/solid/releases/tag/v2.0.0-rc.0).
- **Major API cleanup:** `createResource`, manual `batch`, `startTransition`/`useTransition`, `on`, `createComputed`, `produce`, and `createMutable` are removed or replaced by ordinary async memos, automatic microtask batching plus `flush()`, split effects, and draft-first stores. Existing 1.x apps need migration work. Sources: [RC release](https://github.com/solidjs/solid/releases/tag/v2.0.0-rc.0), [migration guide](https://github.com/solidjs/solid/blob/next/documentation/solid-2.0/MIGRATION.md).
- **Core adds mutations and optimistic state** through `action`, `createOptimistic`, and `createOptimisticStore`; boundaries are reframed as `<Loading>`, `<Errored>`, and `<Reveal>`. Source: [RC release](https://github.com/solidjs/solid/releases/tag/v2.0.0-rc.0).
- **Tooling moved to native compilation.** `@solidjs/vite-plugin` uses an OXC/Rust compiler by default, while Babel remains optional. Source: [RC release](https://github.com/solidjs/solid/releases/tag/v2.0.0-rc.0).
- **Still experimental:** reactive server components behind `serverFunctions: { components: true }`; maintainers say a fuller announcement comes after 2.0 stable. Source: [RC release](https://github.com/solidjs/solid/releases/tag/v2.0.0-rc.0).
