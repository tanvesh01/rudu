# SolidJS ecosystem updates — August 15, 2026

- **SolidStart 2.0 became stable on August 4, 2026.** It moved from Vinxi to Vite's Environment API and Nitro v3. Migration includes `app.config.ts` → `vite.config.ts`, `solidStart()`, updated HTTP/runtime imports, and deployment/middleware changes. Sources: [stable announcement](https://github.com/solidjs/solid-start/discussions/2281), [2.0 release](https://github.com/solidjs/solid-start/releases/tag/%40solidjs%2Fstart%402.0.0), [migration guide](https://docs.solidjs.com/solid-start/v2/migrating-from-v1).
- **But the longer-term direction changed nine days later:** Solid 2.0 RC introduced `start: true` in `@solidjs/vite-plugin` and announced that **Start mode will replace SolidStart**. SolidStart remains maintained, so production apps do not suddenly break; migration is intended to be mechanical for many apps. Source: [Solid 2.0 RC release](https://github.com/solidjs/solid/releases/tag/v2.0.0-rc.0).
- **Start mode is a Vite-native serving layer:** SPA/static output by default, optional SSR, filesystem routing via a router-neutral package, core server functions, and a web-standard Fetch handler for deployment. Source: [Solid 2.0 RC release](https://github.com/solidjs/solid/releases/tag/v2.0.0-rc.0).
- **Solid Router 2.0 ships with the RC** and adds typed routes, params, and navigation. Solid Meta 1.0 becomes a thin layer over the core head registry. The RC announcement says Solid Primitives, Kobalte, Solid Testing Library, Storybook, and AG Grid are usable with the RC, but third-party compatibility should still be checked package-by-package. Source: [Solid 2.0 RC release](https://github.com/solidjs/solid/releases/tag/v2.0.0-rc.0).
